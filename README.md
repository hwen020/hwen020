## Selected projects

**Travel Desk** is an enterprise travel and expense demo covering requests, approvals, simulated booking, reimbursement, and reconciliation. It uses Python and SQLite behind a browser interface, with versioned travel policies and role-specific workflows. [GitHub repository](https://github.com/hwen020/travel-desk-demo) · [Live demo](https://travel-desk-demo.onrender.com/)

**Enterprise Operations AI** demonstrates enterprise workflow automation with versioned quotations, rule-based agents, approval gates, and isolated demo sessions. [GitHub repository](https://github.com/hwen020/enterprise-operations-ai) · [Live demo](https://enterprise-operations-ai.onrender.com/)

**Wearable Mobility Research Pipeline** processes synthetic GPS data, applies quality checks, and presents mobility analyses in an interactive dashboard. [GitHub repository](https://github.com/hwen020/wearable-mobility-research-pipeline) · [Live demo](https://wearable-mobility-research-pipeline.onrender.com/)

**Aging Genomics Lab** supports reproducible age-association analyses of public gene expression and methylation studies through a Python pipeline and Streamlit interface. [GitHub repository](https://github.com/hwen020/aging-genomics-lab) · [Live demo](https://aging-genomics-lab.onrender.com/)

**Culinary Explorer** combines a React interface with a FastAPI backend for restaurant discovery, semantic search, and interactive maps. [GitHub repository](https://github.com/hwen020/culinary-explorer) · [Live demo](https://culinary-explorer-demo.onrender.com/)

**Job Application Agent** demonstrates human approval gates and audit trails in a synthetic job application workflow, with evidence-linked document generation and a mock applicant tracking system. [GitHub repository](https://github.com/hwen020/job-application-agent) · [Live demo](https://job-application-agent-demo.onrender.com/)
